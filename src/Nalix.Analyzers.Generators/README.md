# Nalix.Analyzers.Generators

> Roslyn-based incremental source generators automating AOT-safe packet serialization, registration, and configuration binding.

**Nalix.Analyzers.Generators** is the compile-time execution engine of the Nalix ecosystem. By replacing runtime reflection and dynamic Intermediate Language (IL) emission with static C# source code generation, it enables sub-nanosecond processing speeds and full compatibility with Native AOT compilation and trimmed deployments.

## Source Generators

| Generator | Code Emitted / Purpose | Trigger Criteria / Attributes |
| :--- | :--- | :--- |
| **`SerializeFormatterGenerator`** | Zero-allocation `IFormatter<T>` implementations that statically serialize and deserialize packable types. | Classes, structs, or records decorated with the `[GenerateFormatter]` attribute. |
| **`PacketRegistryGenerator`** | Static opcode-to-type lookup mapping and poolable object factory registration helpers. | Classes implementing `IPacket` decorated with the `[Packet(opcode)]` attribute. |
| **`PacketSchemaGenerator`** | Reflection-free binary serialization schemas mapping property layouts and fixed size constraints. | Classes with layout attributes (`[SerializeOrder]`, `[SerializeHeader]`, `[SerializeIgnore]`). |
| **`ConfigurationGenerator`** | Zero-reflection INI configuration binding, parsing, default writing, and DataAnnotations validation helpers. | Classes inheriting from the `ConfigurationLoader` base type. |

## Key Namespaces

| Namespace | Purpose | Key Types |
| :--- | :--- | :--- |
| `Nalix.Analyzers.Generators` | Root namespace containing all Roslyn incremental source generators implementing `IIncrementalGenerator` | `SerializeFormatterGenerator`, `PacketRegistryGenerator`, `PacketSchemaGenerator`, `ConfigurationGenerator` |
| `Nalix.Analyzers.Generators.Internal` | Internal parsing metadata helper classes and syntax analyzers | `KnownNames`, `SerializationMember`, `SerializationType` |

## Installation & Setup

Source generators are referenced as analyzer dependencies. They run during compile-time inside the compiler or IDE process and do not introduce runtime DLL dependencies:

```xml
<ItemGroup>
  <!-- Reference the generator as a compile-time analyzer -->
  <ProjectReference Include="..\Nalix.Analyzers.Generators\Nalix.Analyzers.Generators.csproj"
                    OutputItemType="Analyzer"
                    ReferenceOutputAssembly="false" />
</ItemGroup>
```

## Code Generation Transformations

### 1. Zero-Allocation Serialization (`SerializeFormatter`)

#### Developer Source Input:
```csharp
using Nalix.Abstractions.Serialization;

[GenerateFormatter]
public partial class PlayerMovePacket
{
    [SerializeHeader(0)]
    public int PlayerId { get; set; }

    [SerializeOrder(0)]
    public float X { get; set; }

    [SerializeOrder(1)]
    public float Y { get; set; }
}
```

#### Emitted Compiler Source Output (`PlayerMovePacket.g.cs`):
```csharp
// <auto-generated/>
#nullable enable
namespace MyGame.Packets;

public partial class PlayerMovePacket : global::Nalix.Abstractions.Serialization.ISerializable
{
    public void Serialize(ref global::Nalix.Abstractions.Serialization.SpanWriter writer)
    {
        writer.WriteInt32(this.PlayerId);
        writer.WriteSingle(this.X);
        writer.WriteSingle(this.Y);
    }

    public void Deserialize(ref global::Nalix.Abstractions.Serialization.SpanReader reader)
    {
        this.PlayerId = reader.ReadInt32();
        this.X = reader.ReadSingle();
        this.Y = reader.ReadSingle();
    }
}
```

### 2. AOT-Safe Configuration Binding (`ConfigurationLoader`)

#### Developer Source Input:
```csharp
using System.ComponentModel.DataAnnotations;
using Nalix.Environment.Configuration;

[IniComment("Main Server Configuration")]
public partial class ServerConfig : ConfigurationLoader
{
    [IniComment("Port to listen on (1024 - 65535)")]
    [Range(1024, 65535)]
    public int Port { get; set; } = 8080;

    [IniComment("Bind Address")]
    [Required]
    public string Address { get; set; } = "127.0.0.1";
}
```

#### Emitted Compiler Source Output (`ServerConfig.g.cs`):
```csharp
// <auto-generated/>
#nullable enable
using System;
using Nalix.Environment.Configuration;

namespace MyGame.Config;

partial class ServerConfig
{
    protected override void CopyPropertiesTo(global::Nalix.Environment.Configuration.ConfigurationLoader other)
    {
        if (other is ServerConfig t)
        {
            t.Port = this.Port;
            t.Address = this.Address;
        }
    }

    protected override void BindProperties(global::Nalix.Environment.Configuration.IniConfig configFile, string section)
    {
        try
        {
            var _v_Port = configFile.GetInt32(section, "Port");
            if (_v_Port.HasValue)
                this.Port = _v_Port.Value;
            else
            {
                configFile.WriteComment(section, "Port", "Port to listen on (1024 - 65535)");
                configFile.WriteValue(section, "Port", this.Port.ToString());
            }
        }
        catch (Exception ex) when (global::Nalix.Abstractions.Exceptions.ExceptionClassifier.IsNonFatal(ex))
        {
            System.Diagnostics.Trace.TraceError($"Configuration binding failed for section={section} key=Port: {ex.Message}");
        }

        try
        {
            var _v_Address = configFile.GetString(section, "Address");
            if (!string.IsNullOrEmpty(_v_Address))
                this.Address = _v_Address;
            else
            {
                configFile.WriteComment(section, "Address", "Bind Address");
                configFile.WriteValue(section, "Address", this.Address ?? string.Empty);
            }
        }
        catch (Exception ex) when (global::Nalix.Abstractions.Exceptions.ExceptionClassifier.IsNonFatal(ex))
        {
            System.Diagnostics.Trace.TraceError($"Configuration binding failed for section={section} key=Address: {ex.Message}");
        }
    }

    protected override void ValidateDataAnnotations()
    {
        if (this.Port < 1024 || this.Port > 65535)
            throw new global::System.ComponentModel.DataAnnotations.ValidationException("Port must be between 1024 and 65535.");
        if (this.Address == null)
            throw new global::System.ComponentModel.DataAnnotations.ValidationException("Address is required.");
    }
}
```

## Architectural Constraints

- **Incremental Compilation Performance:** Generates source code via `IIncrementalGenerator` pipelines. This enables caching of intermediate outputs, protecting IDE typing latency and compiler thread resources.
- **Zero Assembly Coupling:** Types are discovered and parsed using semantic symbol strings to completely avoid runtime cross-assembly circular references.
- **Full Trimming Compatibility:** By resolving configurations and serializations compile-time, zero reflection dynamic queries are compiled, allowing compilers to perform full tree-shaking and assembly size trimming.
