# Connection Ban Store Options

The `ConnectionBanStoreOptions` class provides configuration settings for persisting dynamic IP bans generated by the DDoS and connection rate violation systems.

## Source Mapping

- `src/Nalix.Network/Options/ConnectionBanStoreOptions.cs`

## Overview

When the `ConnectionGuard` identifies a rate limit or DDoS violation, it generates a progressive IP ban. This store handles writing those active bans to disk to persist security state across application restarts.

## Configuration Table

The options map to INI configuration sections under host/network properties:

| Property | Type | Default Value | Description |
|----------|------|---------------|-------------|
| `Enabled` | `bool` | `true` | Enables or disables persisting banned IPs to disk. |
| `AutoSaveInterval` | `TimeSpan` | `00:05:00` (5 mins) | The recurring interval at which active bans are written out to the file. Must be between 1 minute and 1 hour. |
| `StoreFileName` | `string` | `"banned_ips.bin"` | The file name in the data directory where the binary ban list database is stored. |
| `BanCountDecayWindow` | `TimeSpan` | `7.00:00:00` (7 days) | The duration over which a progressive ban count for an IP decays by 1. Must be between 1 hour and 30 days. |
| `MaxPersistedBans` | `int` | `100,000` | The maximum number of banned IP records to load into memory from the store file (protects against memory exhaustion). |

## Usage Example

### Mutating Options Programmatically

```csharp
using System;
using Nalix.Hosting;
using Nalix.Network.Options;

INetworkApplicationBuilder builder = NetworkApplication.CreateBuilder();

builder.Configure<ConnectionBanStoreOptions>(options =>
{
    options.Enabled = true;
    options.AutoSaveInterval = TimeSpan.FromMinutes(10);
    options.StoreFileName = "active_bans.dat";
    options.BanCountDecayWindow = TimeSpan.FromDays(14);
    options.MaxPersistedBans = 50_000;
});
```

### INI Configuration Format

```ini
[ConnectionBanStore]
; Configuration for persisting banned IP addresses to disk
Enabled = true
AutoSaveInterval = 00:05:00
StoreFileName = banned_ips.bin
BanCountDecayWindow = 7.00:00:00
MaxPersistedBans = 100000
```
