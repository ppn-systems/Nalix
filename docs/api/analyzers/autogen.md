# Auto Generation
 
`Nalix.AutoGenerated` provides Roslyn Source Generators that automate the creation of high-performance networking and serialization code at compile time. This ensures type safety, AOT compatibility, and zero-allocation performance without manual boilerplate.
 
## Source Mapping
 
- `src/Nalix.AutoGenerated/SerializeFormatterGenerator.cs`
- `src/Nalix.AutoGenerated/PacketRegistryGenerator.cs`
- `src/Nalix.AutoGenerated/PacketSchemaGenerator.cs`
- `src/Nalix.AutoGenerated/ConfigurationGenerator.cs`
 
## Key Generators
 
### 1. Serialization Formatter Generator
 
Generates optimized `IFormatter<T>` and `IFillableFormatter<T>` implementations for types marked with the `[GenerateFormatter]` attribute.
 
- **AOT Friendly**: Eliminates the need for `System.Reflection.Emit` at runtime.
- **Pooling Support**: Automatically integrates with the `Create()` pooling pattern for reference types.
- **Direct Access**: Uses direct property/field access for maximum serialization speed.
- **Registration**: Automatically registers generated formatters via a `[ModuleInitializer]`.
 
### 2. Packet Registry Generator
 
Scans the compilation for all classes inheriting from `PacketBase<TSelf>` and generates a centralized registry.
 
- **Automatic Discovery**: No need to manually register every packet type in the system.
- **Fast Lookup**: Uses optimized lookup tables for opcode-to-type mapping.
- **Bootstrap Logic**: Generates the initialization code that populates the `PacketRegistry` at startup.
 
### 3. Packet Schema Generator
 
Generates binary schema metadata for all registered packet types.
 
- **Schema Validation**: Allows for runtime or build-time validation of packet structures.
- **Cross-Language Support**: Provides the foundation for generating client-side code in other languages.
- **Metadata Embedding**: Embeds schema information directly into the assembly for diagnostics.
 
### 4. Configuration Generator
 
Automates the binding and validation logic for `Nalix.Environment.Configuration`.
 
- **Type-Safe Binding**: Generates strongly-typed binding code for `.ini` and other configuration formats.
- **Default Values**: Ensures consistency between code-defined defaults and configuration files.
 
## Benefits of Source Generation
 
- **Performance**: Code is generated as static C#, allowing the JIT (or AOT compiler) to optimize it fully.
- **Diagnostics**: Generators work alongside [Analyzers](./index.md) to report errors (like missing `Create()` methods) during the build process.
- **Zero Reflection**: Avoids the performance overhead and linker-trimming issues associated with runtime reflection.
